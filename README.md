# Kennya Kamal Portfolio

Static portfolio website built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Put Kennya's profile photo in `assets/profile.jpg`.
2. Put her CV in `documents/CV-Kennya.pdf`.
3. Replace the `YOUR PHOTO` placeholder in `index.html` with an `<img>` if desired.
4. Upload the whole folder to GitHub and enable GitHub Pages.
